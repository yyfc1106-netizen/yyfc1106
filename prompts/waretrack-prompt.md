# Prompt: "WareTrack", an isometric 3D warehouse-management dashboard that feels like a strategy game

Reverse-engineered from the 72 s demo video in https://x.com/DilumSanjaya/status/2106426962738880879 ("Industrial software doesn't have to feel like industrial software. Manage warehouses like you're playing a strategy game. Built with Opus 5.5"). The author's real prompt is not public; this is a reconstruction of what the video shows. Attach 3-5 frames of the video (default view, a selected pallet, a selected forklift, a selected truck, the cold-store site) to the prompt as visual references.

---

## Goal
Build a client-only web app (no backend) called **WareTrack**: a live, simulated operations dashboard for a logistics company, rendered as a clean isometric 3D "miniature city" (clay / low-poly toy look) with frosted-glass UI panels floating over it. It must feel like a polished strategy game, not enterprise software. Everything on the screen is driven by one shared simulation, so clicking a 3D object, a table row or a timeline step selects the same entity everywhere.

## Visual language (this is what makes it look like the demo)
- **Palette**: near-white lavender-blue ground (#e9eefc to #f6f8ff), one strong brand blue (#2f5cff / #2447d6) for buildings, roofs, trucks and pallets of plastic containers, a warm cardboard tan for boxes, safety yellow/orange for forklifts, soft teal/white/orange only for third-party truck liveries, soft green for trees and "OK" states, amber for warnings. No black, no harsh outlines.
- **Geometry**: everything is built from rounded boxes and cylinders (three.js `RoundedBoxGeometry`), chunky proportions, small details that read at a distance (dock doors with blue frames, corrugated roof ribs, roof fans, window strips, pallets with shrink-wrap, cardboard boxes with a tape stripe, racking with orange beams and blue uprights, trees as pale-green lollipops, fences with translucent panels, painted yellow parking-bay outlines on the asphalt, white dashed lane markings, bollards).
- **Lighting**: soft, high-key. One warm key light with soft shadows, a big hemisphere/ambient fill, a subtle environment map for gentle sheen, ambient-occlusion (N8AO / SSAO) for the contact darkening that sells the clay look, a faint distance fog into the background colour, ACES or neutral tone mapping. Shadows are light and bluish, never black.
- **UI**: frosted-glass cards (backdrop-filter blur, 1 px white border, large radius 16-20 px, soft shadow), Inter-like font, tiny uppercase eyebrow labels, KPI numbers with small green delta chips, status pills (green "Loading / In Stock / Operational", amber "Low Stock / At gate / Charging", blue "En route / Docking", grey "Idle / Available"), progress bars, small circular icon buttons. The 3D scene fills the whole viewport; the panels leave the centre free.

## Scene content
- A city block with roads (lane markings, crossings), grass strips with trees and bushes, background low-rise buildings, a harbour container (teal "MAERA LINE") at one site.
- **Five sites**, each a different layout so the site switch is dramatic: WH-01 Riverside Hub (Newark NJ, 2 dock doors, racks, container yard), WH-02 Northgate DC (long building with 6+ dock doors, solar panels, roof units), WH-03 Eastport Cold Chain (cold store, roof condensers, 3 bays, silos), WH-04 Southfield Cross-Dock (large blue sawtooth roof, 6 bays, "In/Out" doors), WH-05 Westgate Robotics Hub (robotic doors, glass-fronted offices). Building signage "WareTrack · WH-0x name".
- **Entities**: trucks (cab + box trailer with liveries WareTrack blue, Nordline white/teal, Cargoviva white/orange, Bluepeak white/blue), forklifts (yellow, driver visible, forks, lift mast), pallets (cardboard boxes, blue plastic crates, shrink-wrapped white goods), pins above pallets that need attention, yard slots outlined in yellow, forklift charging bays (green pad).
- **Selection feedback**: a soft blue corner-bracket frame and a small floating chip ("FL-11 · Loading truck", "TRK-2372 · Docking") above the selected object, a pulsing ring on the ground, other objects slightly dimmed.

## Simulation (must keep running, all in simulated minutes)
Entity state machines with smooth movement along waypoint paths (no teleporting):
- **Truck**: En route (ETA counts down) -> At gate (waits for yard clearance) -> Docking (reverses into its bay, "4 m left" distance counts down) -> Loading or Unloading (cargo n/N pallets advances as forklifts shuttle pallets between truck and dock) -> Departing -> next shipment. Bays free up and are reassigned.
- **Forklift**: Idle -> Loading/Unloading truck (carries a pallet along a path, shows "Carrying PAL-1091 · LED Panel 60x60") -> Charging (battery rises) -> Idle; battery drains while working; "Moves today" and speed update.
- **Site KPIs** change over time (stock on hand +/- pallets, trucks on site, on-time delivery), and each site has its own seeded data (stock, bay counts, forklift fleet, inventory with some "Low Stock" items).
- Shipment timeline step times and "13 min left" values are derived from the simulation clock; the clock chip shows simulated HH:MM and ticks.

## Interaction
- Orbit-limited isometric camera (fixed elevation range, azimuth rotate by the two arrow buttons in 45-degree animated steps, drag to pan, wheel/pinch to zoom, home = default framing). Smooth fly-to when selecting an entity, a site, or a row; ease in/out.
- Hover highlights an object and shows a small tooltip; click selects; Esc or X clears the selection back to the site view. `/` focuses search; search results (sites, trucks, forklifts, pallets, shipments) select and fly to the match.
- Site switcher animates the camera to the new depot and cross-fades all panels.
- Everything keyboard-reachable, `prefers-reduced-motion` respected. Responsive: on narrow screens the side panels collapse into a bottom sheet.

## Stack and quality bar
- Vite or plain ES modules + three.js (+ postprocessing / N8AO), TypeScript preferred, no backend; state in a small store (e.g. zustand-like) fed by the simulation tick; UI in plain DOM or React; all models procedural (no external assets) and built from shared geometries and instanced meshes so 5 sites with dozens of entities stay at 60 fps on a laptop. Page interactive in about a second (build the first site first, build the others lazily).
- Fixed isometric look must survive any window size (orthographic or low-FOV perspective, fit-to-site framing).
- Typography and spacing consistent through CSS variables; light theme only is fine.

## Process and verification
1. Static scene of one warehouse, trucks, forklifts, pallets, lighting and AO until a screenshot looks like the clay/isometric reference. 2. Camera, selection, flying. 3. Simulation and state machines with unit tests (truck/forklift transitions, bay allocation, conservation of pallets). 4. All panels bound to the store. 5. Five sites, site switcher, search. 6. Polish, performance, responsive.
After each phase run the app in a real browser (Playwright), take screenshots at 1920x1080 and 390x844, compare against the reference frames, and drive every control (site switch, search, tabs, camera buttons, row clicks, selection, Esc) asserting the panels and the 3D selection agree. Do not report done on a build that merely compiles.
